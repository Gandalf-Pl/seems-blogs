这一周，AI 行业被两份报告和一连串安全事件拽进了一个尴尬的问题：你调用的那个模型，真的是你以为的那个吗？

9 月 9 日，Anthropic 发布[九月威胁情报报告](https://www.anthropic.com/threat-intelligence-report-september-2026)，内容之劲爆在中文互联网上几乎没有得到对等的讨论。报告披露：DeepSeek 和 Moonshot（月之暗面）被发现将部分用户请求**静默转发给 Claude**——用户以为自己在和 Kimi 或 DeepSeek 对话，实际背后是 Claude Opus 在作答。手法相当精细：先用字符串匹配识别出正在使用 Claude Code、Claude Agent SDK 等第三方编程工具的用户，再把这部分请求改道；更关键的是「跨会话回放攻击」——Claude 的 API 出于防蒸馏设计，只返回推理签名而非完整思维链，而这两家公司保存签名后开启新会话，诱使 Claude 把签名还原成完整推理痕迹，从而成规模地收割 CoT 数据用于训练自家模型。Anthropic 观察到的交换规模，仅智谱一家在 6、7 月的 17 天里就超过 340 万次。

几乎同一时间，安全侧的坏消息密集落地：一个「pinned」插件成为四个主流编程智能体的零点击后门；一段被攻陷的营销脚本在 10 万余个网站上传播恶意代码；西班牙记录了首例归因于自主智能体的数据泄露。

模型层面的失控已经被讨论了两个月，这次不一样。这次的问题不在模型「想干什么」，而在产业链「实际干了什么」。

## 蒸馏不是原罪，欺诈才是

先把事实边界划清楚。蒸馏本身是行业公开的秘密，OpenAI 当年蒸馏 Google 的模型，DeepSeek 蒸馏过 GPT，各家都在互薅。用对手模型的输出来训练自己的模型，法律上灰色，行业内默认，几乎无法取证。

但这次披露的性质完全不同，它越过两条线。第一条是**用户知情权**：DeepSeek 和 Moonshot 的客户并不知道自己的请求——其中可能包含企业代码、内部文档等敏感信息——被转发给了第三方 Anthropic。这不是竞争策略问题，是数据处理问题，直接踩在中国《生成式人工智能服务管理暂行办法》和个人信息保护法的红线上。第二条是**系统性欺骗**：不是拿公开 API 做研究，而是伪装成自家产品在线提供服务，用对手的能力冒充自己的能力交付给客户。这在任何行业都不叫学习，叫假冒伪劣。

最有讽刺意味的是这件事反过来证明了什么。你什么时候见过有人蒸馏比自己差的模型？蒸馏的目标是推理链的质量，而推理链恰恰是各家旗舰模型差异最大的地方。一个"挂羊头卖狗肉"的行为，本身就是对 Claude 推理能力最诚实的广告。那些在排行榜上直逼 frontier 的开源模型，其能力的真实成色需要重新打量——哪些是自研架构的红利，哪些是对着 Opus 批改出来的作业，外界已经很难区分。

## 供应链安全：能力越强，攻击面越大

第二波事件暴露的是同一问题的另一面。当模型以 Agent 形态进入生产环境，它不再是聊天框里的文本生成器，而是握着代码库权限、浏览器凭证、生产环境钥匙的执行者。「pinned」插件后门之所以危险，是因为它不需要用户做任何事——四个主流编程智能体加载一个被篡改的插件，就等于把自家门钥匙交给了攻击者。10 万个网站感染恶意脚本则说明，针对 AI 工作流的供应链攻击已经开始复制传统软件供应链的成熟打法：不攻你的模型，攻你的依赖。

这两波事件合起来指向同一个结构性判断：**AI 行业正在经历软件业 2014 年 Heartbleed 时刻**——基础设施的能力跑在了治理前面，而所有人都以为先进生产力可以豁免基础 hygiene。

## 三个值得从业者认真对待的预判

第一，**模型身份认证会变成硬需求**。Anthropic 在这次事件后开始收紧推理签名机制，但这只是止血。往深处看，"如何证明回应你的确实是某模型"和"如何证明某模型的能力确实来自自己的训练"会成为两类基础协议：前者类似 TLS 证书，后者类似训练数据溯源。谁率先把这层做进 API 标准，谁就拿到了下一代基础设施的入场券。据说头部实验室已经在评估 cryptographic response signing，这不是技术炫技，是被逼出来的。

第二，**企业采购 AI 将增加"供应链尽调"维度**。过去企业选模型看三件事：能力、价格、合规资质。接下来要加第四件：供应链清白度——你的训练数据有没有争议，你的推理服务有没有暗路由，你的插件生态有没有审计。就像今天采购云服务要看等保和 SOC 2 一样。这个变化对大厂是合规成本，对小厂是生死门槛。

第三，**中文开源模型的全球信任将面临一次定价**。这次报告披露后，海外社区对国产模型的讨论已经从"便宜好用"转向"数据从哪来"。信任折价的直接后果是：同等能力下，企业客户愿意支付溢价给"干净"的供应商。讽刺的是，中国模型过去一年最好的故事恰恰是生态融入——AWS Bedrock 同时上架了 DeepSeek、Kimi、GLM、Qwen，国产芯片因英伟达受限而一卡难求。如果蒸馏欺诈坐实，输掉的不只是几家公司的声誉，而是整个中国开源阵营好不容易积累的渠道信任。这个代价远大于蒸馏本身省下的训练成本。

## 结语

行业总会有一些时刻，把积累已久的默契撕开口子。这一周的启示是：模型能力的军备竞赛越激烈，"信任"作为资产的定价就越高。蒸馏能抄走分数，抄不走产生分数的过程；套壳能骗过用户，骗不过供应链审计。

对从业者，最实际的建议只有一条：把你接进生产环境的每一个模型、每一个插件、每一段脚本，当成你会审计的开源依赖来对待。因为攻击者已经这么做了。
