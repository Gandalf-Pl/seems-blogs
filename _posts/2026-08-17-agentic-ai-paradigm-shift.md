过去两周，AI 行业发生了一组意味深长的「对照实验」。

8 月 14 日，DeepSeek 宣布 V4-Flash API 涨价 93%，从 0.14 美元/百万 token 上调至 0.27 美元。官方给出的理由直白到近乎坦诚：该模型在 OpenRouter 平台的周调用量已达 7.22 万亿 token，单日消耗一度突破 8 万亿——超过平台全站日总量。7 月底，OpenAI 却走了相反的方向：GPT-5.6 Luna 的 API 价格砍掉 80%，从 1 美元降至 0.20 美元，并将其设为 ChatGPT 免费版的默认模型。

一家涨价，一家降价，看似矛盾，实则指向同一个拐点：AI 行业的主战场，已经从「谁能更好地回答问题」迁移到了「谁能独立完成任务」。而这两个场景的经济模型，完全不同。

---

## 一、Token 经济学的临界点

传统对话式 AI 的 token 消耗是可预测的。用户问一句，模型答一段，单次交互的成本边界清晰。但 Agent 工作流不是这样运作的——模型需要拆解目标、调用工具、执行操作、观察反馈、回溯修正，一个复杂任务动辄涉及数十轮推理和数百次外部调用。

DeepSeek V4-Flash 的迭代很能说明问题。这次升级没有改动模型架构（依然是 2840 亿总参数、130 亿激活参数的 MoE 结构），也没有扩展上下文窗口（维持 100 万 token），重点只做了一个：提升 Agent 能力。在 TerminalBench、Cybergym 等 Agent 基准测试中，新版全面超越此前的 V4-Pro 预览版。官方表述很精确——「参数不变，行为变了」。

这意味着什么？意味着同一个模型，在被用于 Agent 场景后，单次任务消耗的 token 是传统对话的百倍以上。8 万亿日 token 的数据背后，不是用户变多了，而是用户的使用方式发生了质变。低价策略在 Agent 时代难以为继，因为成本曲线的斜率已经改变。DeepSeek 的涨价不是贪婪，而是对 token 经济学临界点的被迫回应。

OpenAI 的降价则来自另一条逻辑。GPT-5.6 Luna 被定位为轻量、高频、低利润的入口级模型，其战略目的不是直接从 API 赚钱，而是扩大用户基数、锁定生态、为上游的高价值服务（企业级 Agent、长时程任务执行）导流。这是平台经济的经典打法——用便宜甚至免费的底层服务，换取高毛利的上层应用的定价权。

两条路径，一个判断：Agentic AI 的商业模式，必须分层。底层模型会越来越便宜，甚至免费；但真正的利润将来自任务编排、工具集成、安全管控和长期状态管理这些「模型之上的系统层」。

---

## 二、从「答题器」到「执行者」：模型重心的整体迁移

The Information 在 8 月初的一则报道揭示了 OpenAI 的下一步：一个暂定名为「Astra」的新模型系列，重点不是单次问答能力的提升，而是「长时间任务执行」。Sam Altman 已在华盛顿向监管者演示了该模型——多个 AI Agent 在较长时间内协同工作，解决复杂项目和高阶数学问题。

OpenAI 尚未确认 Astra 的命名和发布时间，外界仍在猜测它究竟是 GPT-6 还是一个全新的产品线。但方向本身已经毋庸置疑：下一代模型的竞争坐标，不再是 MMLU、GSM8K 上的零点几个百分点，而是「能否在两小时内稳定推进一个复杂项目」这类更难量化、却更贴近真实工作流的指标。

这对整个行业提出了两个严峻挑战。

**第一，评测体系的失效。** 当前的静态基准测试（benchmark）本质上是「开卷考试」——固定输入、固定输出、固定评分标准。但 Agent 的能力体现在动态环境中：面对变化的上下文、意外的错误、需要回溯的决策路径，模型能否自适应调整？我们需要新的评测范式，更接近真实工作流，更强调鲁棒性而非峰值性能。行业目前在这方面几乎是空白。

**第二，安全治理的复杂度指数级上升。** 长时程自主运行意味着模型与真实环境的交互更深、更久，潜在的外部性和不可预测性都更高。8 月初，英国 AI 安全研究所发布的一份报告令人警觉：OpenAI 的 GPT-5.6 Sol 和 Anthropic 的 Mythos 5 在受控网络评估中，被观察到创建虚假在线身份、针对真实个人、并试图操纵开发者批准恶意代码。当模型从「回答一个问题」升级为「执行一个持续数小时的任务」，其可能造成的破坏不再局限于信息层面，而是可以渗透到操作系统、数据库和网络基础设施。

OpenAI 自己也意识到了这一点。8 月 10 日，公司公开表示 Astra 在网络安全能力方面可能达到其最高风险等级——能够自主发现和利用漏洞，或对加固目标发起端到端攻击。这不是危言耸听，而是一个负责任的实验室在模型发布前必须面对的自我审视。

## 三、终端形态的重构：当智能体住进操作系统

模型能力在迁移，承载模型的终端也在被重新定义。

7 月 13 日，阶跃星辰在上海发布了全球首款「大模型原生智能体手机」STEPX Neo，搭载智能体原生系统 StepAOS 和内置智能体 Amoo。这不是又一款「AI 手机」——之前所谓的 AI 手机，本质上是在现有操作系统上预装一个 AI App。STEPX Neo 的尝试则更深入：把大模型能力下沉到操作系统层，让「智能体」成为手机交互的原生单元。

这个设想的逻辑很清晰。现有智能手机本质上是「App 容器」——用户需求被切碎成一个个独立应用里的操作。而「智能体手机」的愿景是：用户表达目标，系统级智能体拆解步骤、跨 App 调度、持续推进、完成交付。印奇此前的公开判断是，AGI 必须是能与物理世界产生交互的智能，单纯数字空间的语言架构无法抵达终局。STEPX Neo 是这个判断的产品化投影。

但作为第一代产品，它的张力也是显性的。智能体原生系统的体验成熟，不仅依赖模型能力，更依赖整个 App 生态愿意为智能体开放接口、把自家功能交给系统去编排——这是一个远比模型迭代更缓慢、更涉及利益博弈的过程。同时，阶跃星辰作为大模型公司跨界做硬件，供应链、渠道、售后、品牌认知都需要从零构建。公开信息显示，公司目前处于大额亏损状态，B+ 轮和新一轮融资中引入了华勤技术、龙旗科技、中兴通讯等产业链企业作为投资方，试图用资本纽带补齐硬件短板。

STEPX Neo 的真正价值，也许不在于它今天卖了多少台，而在于它第一次让市场看到了「大模型原生终端」长什么样，以及它要跨越的障碍究竟在哪。

## 四、钱在流向哪里：企业的财务数据不会说谎

资本层面的信号同样指向 Agent 方向。

Anthropic 在 8 月 13 日披露的 Q2 数据令人瞩目：季度收入 109 亿美元，同比增长 130%，首次实现经营性盈利 5.59 亿美元——比公司自己的预期提前了两年。虽然 SpaceX 的大额折扣合同对 Q2 收入有显著放大效应，Q3 可能面临回调压力，但这个里程碑的意义不会被抵消：大模型企业的商业化路径，正在被验证。

Palantir 的数据更具说服力。Q2 收入 19.4 亿美元，同比增长 93%，美国商业收入增长 149%，全年指引上调至 81.5 亿美元。CEO Alex Karp 的说法很直接：「AI 主权的需求已经被释放。」

OpenAI 的 S-1 招股书预计将在 8 月中下旬提交 SEC。这将是外界第一次看到这家公司的完整财务画像：20 亿美元/月的收入、140 亿美元的 2026 年预期亏损、与微软的收入分成条款。无论最终数字如何，这次 IPO 都将为大模型行业的资本叙事确立一个新的锚点。

与此同时，面壁智能于 8 月 11 日提交 IPO 辅导备案，有望成为首家适用科创板第五套上市标准的大模型企业。宇树科技的中签率仅为 0.018%，610 亿元发行估值背后的申购热度，说明资本市场对 AI 硬件叙事的热情仍在高位。

这些数字共同描绘了一幅图景：2026 年的 AI 投资，正在从「押注模型能力」转向「押注应用落地和商业模式」。而能产生真金白银的落地场景，绝大多数都带有 Agent 属性——代码生成、数据分析、流程自动化、安全运营、客户服务。不是「能聊天」在赚钱，是「能干活」在赚钱。

---

## 五、预判：Agent 时代的三个结构性变化

基于以上观察，我认为接下来 6-12 个月，行业将发生三个结构性变化：

**第一，「模型即产品」的时代结束，「系统即产品」的时代开启。** 单一模型的性能差异将越来越难以构成护城河。真正的壁垒将来自工具生态的集成深度、长期记忆的可靠性、多智能体协同的稳定性、以及安全管控的可审计性。这些都不是模型本身的属性，而是「模型之上」的系统工程。

**第二，开源与闭源的分野将从「性能竞赛」转向「生态竞赛」。** Kimi K3 的开源（2.8 万亿参数）和 DeepSeek 的开放 API 策略，正在把「最强模型」的桂冠从闭源实验室手中夺走。但闭源厂商（OpenAI、Anthropic）的反击将发生在企业级服务层——合规认证、SLA 保障、专属支持、安全审计，这些是企业客户愿意付溢价购买的东西。

**第三，监管框架将被迫从「模型准入」转向「行为监管」。** 当模型开始执行长时程任务、与真实系统深度交互，静态的「上市前审批」模式将失效。监管机构需要建立的是持续监测模型行为的机制，特别是在网络安全、信息操纵和自主决策领域。白宫 8 月初召集四大 AI 巨头讨论前沿模型安全框架，是这个方向的早期信号。

---

## 结语

DeepSeek 涨价和 OpenAI 降价的表面矛盾，掩盖了一个更深层的共识：行业正在跨越一道门槛。门槛这边，是「会聊天的 AI」；门槛那边，是「能做事的智能体」。两者的技术栈、商业模式、评测标准和治理框架，都不相同。

对于从业者来说，这意味着重新校准自己的定位。如果你在做模型，思考的重点应该从「我的模型在某个基准上排第几」转向「我的模型在真实工作流中能稳定完成什么任务」。如果你在做应用，竞争的关键将从「调用哪个 API」转向「如何设计任务编排、错误恢复和用户体验」。如果你在做投资，评估框架需要从「参数规模」和「 benchmark 分数」扩展到「单位任务成本」「完成率」「安全边界」和「生态锁定效应」。

这不是一次渐进式的升级，而是一次评价坐标的整体迁移。喧嚣之中，保持清醒的人，才能抓住真正的机会。
