DeepSeek 在5月24日宣布将 V4-Pro 的75%折扣永久化。这不是一条普通的价格新闻。当一家中国头部实验室把 frontier-class 推理模型的价格压到国际竞品的四分之一时，它传递的信号远比「竞争激烈」四个字要沉重得多。

AI 行业正在经历一场静默但深刻的商业模式重构。

## 一、价格不是武器，是阶段

很多人把这次降价解读为「价格战」——中国厂商用成本优势挤压美国实验室的利润空间。这种理解没有错，但过于表面。

过去两年，AI 行业经历了三个清晰的定价阶段。

第一阶段是「技术溢价期」。2022到2024年，GPT-4 和 Claude 的定价权建立在其不可替代性上。企业愿意为「更好的模型」支付5倍甚至10倍的溢价，因为模型能力本身存在断层——差一档就是可用与不可用的区别。这个阶段，定价逻辑是「能力定价」：我比你聪明，所以我贵。

第二阶段是「锚定竞争期」。2024到2025年，各家模型的能力差距迅速收敛。GPT-4o、Claude Sonnet、Gemini Pro、DeepSeek V3 在多数业务场景中的表现差异缩小到10%以内。竞争焦点从「谁更聪明」转向「谁更便宜」。但此时的降价仍是策略性的——DeepSeek 的年初降价、谷歌的 Gemini Flash 定价，本质上是锚定效应：用低价产品拉低用户对同类服务的支付意愿，再在高端产品上收割利润。

现在进入的是第三阶段——「成本重构期」。DeepSeek 的75%永久降价不是策略，而是结构性的成本宣言。它意味着中国头部实验室已经证明一件事：在模型能力趋同的前提下，他们可以用更低的算力成本、更高效的推理架构，提供同等质量的服务。这不是用亏损换市场份额，而是用工程效率重新定义行业的成本底线。

当成本底线被击穿，原有的定价体系就站不住了。

## 二、价值链正在断裂重组

AI 行业有三层价值链：算力层、模型层、应用层。价格战的冲击波正在逐层传导。

**算力层面临利润挤压。** 英伟达 GPU 的定价权建立在「AI 训练必须依赖高端芯片」的前提上。但当模型推理成本以75%的幅度下降，说明两件事正在发生：第一，模型压缩和量化技术已经成熟，可以在消费级硬件上运行 frontier 模型（Redis 创始人给 DeepSeek V4 打造专用推理引擎，让 Mac 电脑能跑大模型）；第二，国产芯片替代进程加速。华为提出2031年实现1.4nm 晶体管密度，与台积电路线图持平。这意味着中国算力自主可控的时间表比美国政策预期更快。算力层的「英伟达溢价」正在被动摇。

**模型层被迫转向价值定价。** 当 Token 价格降到每百万 token 1元人民币以下，模型厂商无法再通过「卖 Token」盈利。Google 的 Gemini 3.1 Flash-Lite 定价 $0.25/百万 token，Zhipu AI 的 GLM-4.7 低至 $0.11/百万 token——这个价格已经低于带宽成本。模型厂商必须找到新的收入来源：企业级 agent 平台、垂直行业解决方案、或者硬件绑定。Google Cloud 推出 Gemini Enterprise Agent Platform、Anthropic 布局金融和保险专用 agent，都是在为「后 Token 时代」寻找商业模式。

**应用层迎来真正的爆发窗口。** 过去两年，AI 应用创业的最大阻碍是「模型成本 eat 掉毛利率」。当一个 AI 写作工具需要把30%的营收交给模型 API 提供商时，它很难建立可持续的商业模式。现在，模型成本降到原来的四分之一甚至二十分之一，应用层的利润率突然打开了。这就是为什么 Cursor、Windsurf 等 AI 编码工具能在2025年迅速规模化——不是因为它们的技术有多独特，而是因为模型成本下降让它们找到了健康的 unit economics。

## 三、中国模型的「60%份额」意味着什么

中国模型在 OpenRouter 上的使用占比达到60%，这个数字值得反复咀嚼。

OpenRouter 是开发者选择模型的「中立市场」。在这个市场上，用户不受地缘政治、品牌忠诚度或生态锁定的影响，纯粹用脚投票。60%的份额意味着，在全球范围内，价格敏感型开发者正在系统性地向中国模型迁移。

这背后有两层逻辑。

第一层是经济理性。在能力差距缩小到10%以内时，75%的价格优势就是决定性的。一个年消耗100万美元 Token 的初创公司，切换到 DeepSeek 意味着节省75万美元——这足以决定公司的生死。

第二层是生态分化。中国模型正在形成独立的技术生态。蚂蚁百灵的 Ring-2.6-1T 万亿参数模型、华为的昇腾芯片训练、DeepSeek 的专用推理引擎——这些不是孤立的点，而是一条正在闭合的产业链。当中国模型在价格、性能、硬件适配上形成闭环，全球 AI 生态可能分裂为两个平行体系：一个以美国实验室和英伟达芯片为中心，一个以中国模型和国产算力为底座。

这种分裂对应用层的影响是深远的。一个在硅谷开发的 AI 应用，如果目标用户主要在东南亚或拉美，它很可能会选择中国模型——不是因为政治，而是因为成本。商业逻辑会绕过地缘政治的墙。

## 四、预判：AI 行业的「后 Token 时代」

未来12到18个月，AI 行业会发生三件事。

**第一，模型层全面转向订阅和结果定价。** 按 Token 计费会保留，但只作为基础计费单元。主流模式会变成「企业级订阅」+「按任务/按结果计费」。OpenAI 的 Codex 定价、Anthropic 的 Max 计划测试，都是这个方向的预演。当模型厂商无法从 Token 上赚钱，它们就必须从「价值交付」上赚钱——帮企业完成一个客服任务、生成一份合规报告、自动修复一个漏洞。

**第二，Agent 成为真正的商业载体。** 2025年是「智能体元年」的喊声已经很多，但真正的拐点会在2026年下半年到来。因为 Agent 的商业模式天然适配「结果定价」：一个能独立完成报销流程的 Agent，可以按「处理一张发票」收费；一个能自动审查合同的 Agent，可以按「审查一份合同」收费。这种定价方式把模型能力封装成可直接交换的商业价值，绕过了 Token 计价的低效。

**第三，AI 应用创业的黄金窗口打开。** 当模型成本降到可忽略，应用层的竞争焦点重新转向产品能力、用户洞察和场景深耕。2025年的 AI 应用创业，大多被模型成本「卡脖子」；2026年下半年到2027年，会有一批真正健康的 AI 应用公司跑出来。它们的共同特征会是：轻模型依赖、重 workflow 设计、强行业 know-how。

## 结语

DeepSeek 的75%永久降价，表面上是一条价格新闻，实际上是一声发令枪。

它标志着 AI 行业从「技术稀缺期」进入「效率竞争期」。在这个新阶段，模型能力的领先不再自动转化为商业优势，工程效率、成本控制和商业模式创新能力变得同等重要。对中国 AI 产业来说，这是一次用工程能力换取全球市场份额的战略机遇；对美国实验室来说，这是倒逼其从「技术贵族」转向「商业实体」的压力测试。

对于 AI 从业者，最直接的启示是：如果你还在按「调用次数」规划产品成本，你的商业模式可能已经过时了。当 Token 比水还便宜，真正值钱的东西不再是模型的「智力」，而是你把这种智力转化为具体结果的能力。

AI 行业的价格战，才刚刚开始。
