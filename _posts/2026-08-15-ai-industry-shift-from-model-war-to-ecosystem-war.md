2026年8月的第二周，AI行业发生了两件看似 unrelated、实则指向同一方向的大事。

第一件：8月6日，OpenAI、Amazon、Microsoft、Google、Cursor（Anysphere）、Vercel 六家公司联合发布了 Agent Plugins 1.0——一个开放的、供应商中立的 AI 代理技能打包标准。这意味着，开发者写一次 Agent 技能，就能在 ChatGPT、Copilot、Cursor、VS Code 等多个平台间复用。值得注意的是，这个标准底层依赖的是 Anthropic 去年推出的 MCP（Model Context Protocol），但 Anthropic 自己却没有出现在维护者名单上，Claude 也不在首发支持客户端之列。

第二件：8月4日，Palantir 发布 Q2 财报，总营收 19.4 亿美元（同比+93%），美国商业收入 7.64 亿美元（同比+149%），GAAP 净利润 10.6 亿美元。CEO Alex Karp 说了一句话："AI 主权的需求已被释放。" 市场用 25% 的股价涨幅回应了这份财报。

两件事放在一起，一个清晰的信号浮现出来：**AI 行业正在从"模型能力竞赛"转向"生态与商业化竞赛"。** 模型本身的差距在快速收敛，真正的胜负手，变成了谁能把 AI 的能力封装成企业愿意付费的产品、谁能建立开发者离不开的生态、谁能定义下一代人机协作的标准。

---

## 一、Agent Plugins 1.0：六巨头握手， Anthropic 被晾在一边

这件事最耐人寻味的地方不是标准本身，而是参与者和缺席者。

Agent Plugins 1.0 的规范极其克制：一个目录、一个 plugin.json 清单、一个 skills/ 文件夹、一个可选的 mcp.json。没有安装机制，没有应用商店规范，没有权限模型，没有沙箱框架。它解决的问题也极其具体——只是**打包格式**的统一，让不同客户端能识别和加载同一套 Agent 技能。

但这种克制恰恰是成熟的表现。它说明六家公司达成了一个务实的共识：在 Agent 时代，继续各自为战、让开发者给每个平台重写同一套技能，对所有人都是损耗。标准化包装格式，降低的是整个行业的摩擦成本，提高的是 Agent 生态的整体规模。

那为什么 Anthropic 被排除在外？

一个可能的解读是：MCP 协议虽然是 Anthropic 发起的，但 Agent Plugins 1.0 的制定者们选择了一条"去中心化"的路线——用 MCP 作为连接协议，但不让 Anthropic 掌握标准的制定权。Anthropic 的缺席，可能是主动的战略选择（维护 Claude 的差异化定位），也可能是被动的被边缘化。无论如何，这意味着**Agent 生态的标准制定权，已经从协议发明者转移到了平台分发者手中。**

对开发者和企业用户来说，这当然是好事。锁定效应被削弱，技能资产的流动性增强。但对 AI 厂商来说，这意味着一种新的竞争维度：未来的护城河不再是"我的模型最强"，而是"我的平台上有最丰富的 Agent 生态"。

---

## 二、Palantir 的 93%：企业 AI 需求的真实模样

如果说 Agent Plugins 1.0 代表了技术生态层面的转向，那 Palantir 的财报则揭示了商业落地层面的真相。

Palantir Q2 的几个数字值得反复咀嚼：

- 美国商业收入 +149%，达到 7.64 亿美元，与美国政府收入（8.09 亿美元）基本持平
- 单季度签下 220 笔百万美元以上合同，其中 70 笔超过 1000 万美元
- Rule of 40 得分 155%（SaaS 行业的黄金标准是 40%）
- 剩余合同价值（deal backlog）在美国商业领域翻倍至 62.4 亿美元

这些数字说明什么？

**说明企业不是不想买 AI，而是不想买"黑箱 AI"。** Karp 反复提到的"AI 主权"（AI Sovereignty），本质上是在回应企业最深层的焦虑：我花大价钱部署的 AI 系统，会不会把我的核心数据变成别人家的训练素材？我的业务流程会不会被锁定在某个厂商的模型版本更新节奏里？

Palantir 的解法是把 AI 平台做成一个"主权可控"的中间层——企业可以接入各种开源或闭源模型，但数据、决策逻辑、合规审计都留在自己手里。这种定位让它从一家"政府数据分析公司"变成了"企业 AI 操作系统"，TAM（总可触达市场）被打开了数个数量级。

红杉资本的 David Cahn 此前提出过一个尖锐的问题：1.5 万亿美元的 AI 基础设施投入，需要对应 3 万亿美元的用户收入才能回本，而目前 OpenAI 和 Anthropic 加起来年化收入约 800 亿美元，缺口高达 2.9 万亿。Palantir 的财报给出了一个可能的答案：**这个缺口不是不存在，而是正在以企业级部署的速度被填补——只是填补者不是模型公司本身，而是像 Palantir 这样把模型能力"翻译"成企业语言的平台层。**

## 三、中国市场的平行叙事：视频生成与超级入口

把目光拉回国内，8 月的 AI 赛道呈现的是另一幅图景。

快手的可灵 AI 视频生成模型完成近 30 亿美元融资，估值达到 180 亿美元，腾讯、阿里云、百度罕见地同台入股。字节跳动发布 Seedance 2.5 视频生成模型，单次生成时长提升至 30 秒。ChinaJoy 的 70 款 AI 游戏集体亮相，主题定为"与 AI 同游"。

与国际市场"生态标准化 + 企业级落地"的主线不同，中国 AI 行业当前的热点是**视频生成和超级入口争夺**。高盛在最新研报中把 2026 年定义为"关键之年"，核心判断是：中国 AI 的分水岭不在模型，而在"入口能不能闭环"。

字节跳动的豆包 App 日活已突破 1 亿，日均 Token 消耗量国内第一。阿里的通义千问、百度的文心一言在 C 端和 B 端双线作战。DeepSeek-V4-Pro 在 8 月 15 日全面 GA，MIT 许可、开放权重。各家厂商的模型能力差距正在以月为单位收敛，竞争焦点迅速转移到谁能把 AI 嵌入用户做决定的那个瞬间——搜索之前、购物之前、娱乐之前。

这里有一个和国际市场形成有趣对照的现象：**美国市场在推进"Agent 技能跨平台标准化"，以削弱锁定效应；中国市场则在拼命争夺"超级入口"，以建立更强的锁定效应。** 两种路径没有高下之分，只是反映了不同的市场结构和竞争阶段。

## 四、后模型时代的竞争逻辑

把这些线索串起来，一个判断逐渐清晰：**我们正进入"后模型时代"。**

所谓后模型时代，不是说模型不再重要，而是说"谁的模型在 benchmark 上高几个点"已经不再是决定胜负的关键变量。2026 年 8 月的模型格局——Claude Opus 5 在智能和 Agent 能力上领先，GPT-5.6 家族在通用性上保持优势，Qwen 3.8-Max 和 DeepSeek-V4-Pro 在开源阵营紧追不舍——本质上是一个"多强并立、差距收敛"的状态。

真正的竞争转移到了三个层面：

**第一，生态厚度。** Agent Plugins 1.0 是一个信号：未来的 AI 平台之争，越来越像操作系统之争。Windows 战胜 Mac 不是因为在某个版本上性能更好，而是因为生态更丰富。ChatGPT、Copilot、Cursor 在争夺的，是谁能成为 AI 时代的"默认平台"。

**第二，企业落地效率。** Palantir 的爆发证明了一个道理：企业愿意为 AI 付大钱，但前提是解决"主权"和"ROI 可衡量"两个痛点。谁能把 AI 从"实验室玩具"变成"可审计、可治理、可量化回报的生产工具"，谁就能吃到最大的企业预算蛋糕。

**第三，商业闭环能力。** 中国的"超级入口"之争和美国的企业级部署之争，看似方向不同，实则殊途同归——都是在寻找模型能力之外的"价值捕获层"。OpenAI 押注 ChatGPT 广告（目标 250 亿美元年广告收入），Anthropic 坚持 Claude 无广告策略并自建 AI 芯片，Google 推 Universal Commerce Protocol 试图标准化 Agent 购物——这些都是模型公司在寻找"不依赖 API 调用量"的第二增长曲线。

---

## 五、预判：接下来会发生什么

基于以上分析，几点趋势预判：

**1. Agent 标准化会加速，但安全与治理将成为下一个战场。** Agent Plugins 1.0 只是包装层标准化，权限模型、沙箱机制、审计追踪、跨 Agent 协作的治理框架都还是空白。2026 年下半年到 2027 年，这个领域会出现密集的标准制定和产品创新。

**2. 企业级 AI 平台将迎来一轮并购整合。** Palantir 证明了模式的跑通，但市场上还有大量垂直领域的"小 Palantir"。Salesforce、ServiceNow、甚至传统咨询公司（Accenture、McKinsey）都会加速布局，模型公司（OpenAI、Anthropic）也会被迫向下游延伸，从"卖 API"转向"卖解决方案"。

**3. 中国 AI 市场的"入口决胜"将在 2026-2027 年见分晓。** 字节跳动凭借流量优势占据有利位置，但阿里在电商闭环、腾讯在社交关系链上各有壁垒。真正的变量在于：当各家的模型能力趋于同质化，用户到底会因为什么而留在某个平台？答案可能是"习惯"，也可能是"某个不可替代的 Agent 工作流"。

**4. Anthropic 的"被排除"不会持续太久。** 要么它会以某种方式加入 Agent Plugins 的标准化进程（毕竟 MCP 是它发明的，生态影响力不容低估），要么它会推出一个差异化的、更完整的 Agent 框架来与之抗衡。无论如何，Claude 在开发者心中的地位意味着它不会甘于只做旁观者。

---

## 结语

2024 年，行业还在争论"Scaling Law 是否仍然有效"。2025 年，争论变成了"AI 的泡沫会不会破"。2026 年 8 月，答案已经越来越清晰：**AI 不是泡沫，但 AI 的价值捕获方式正在经历一次范式转移。**

模型层在变成"基础设施"——就像电力、带宽、云计算一样，重要但同质化。真正的利润和壁垒，正在向上（平台与生态）和向下（垂直行业解决方案）两个方向迁移。

Agent Plugins 1.0 和 Palantir 的 93% 增长，是同一枚硬币的两面：一面是技术生态的开放与标准化，一面是商业落地的加速与深化。它们共同指向一个结论——

**AI 行业的第一幕（模型竞赛）已经接近尾声，第二幕（生态与商业化竞赛）刚刚开场。** 对从业者来说，这意味着机会窗口的重新分配：模型研究者需要思考"我的技术如何在产品中产生可衡量的价值"，产品经理需要思考"我的工作流如何嵌入用户的日常工作"，创业者需要思考"我的细分领域有没有一个 Palantir 级别的机会"。

舞台已经换了。旧的规则不再适用。新的游戏规则，正在由那些最先想清楚"模型之后是什么"的人书写。
