## 🎉 博客搭建完成

这是我的第一篇博客文章！

### 关于这个博客

- **主题**: [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) —— 极简、现代、功能丰富的 Jekyll 主题
- **部署**: GitHub Pages
- **特性**:
  - 🌙 暗黑模式
  - 🔍 内置搜索
  - 📱 响应式设计
  - 🏷️ 标签和分类
  - 📊 代码高亮

### 快速开始

```bash
# 本地预览
bundle install
bundle exec jekyll serve
```
